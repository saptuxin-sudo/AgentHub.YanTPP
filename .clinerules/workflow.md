# Рабочий процесс в этом репозитории

## Перед началом работы

1. `git status` — дерево должно быть чистым. Все изменения делать в отдельной ветке, никогда не коммитить напрямую в `main`.
2. Если каталога `node_modules` нет — выполнить `npm install`.

## Обязательная проверка результата

Перед тем как сообщить о готовности задачи, выполнить:

1. `npm run lint` — проверка типов (`tsc --noEmit`). Должно быть без ошибок.
2. `npm run build` — production-сборка Vite. Должна проходить успешно.
3. При изменениях в интерфейсе — `npm run dev` и проверить http://localhost:3000 (в этом окружении HMR отключён через `DISABLE_HMR`, страницу нужно перезагружать вручную).

Если проверка не проходит — исправить ошибки, а не отключать проверку.

## Правила правок

- Минимальные точечные изменения: не переписывать файл целиком, если достаточно правки фрагмента.
- Сохранять существующий формат кода, отступы, порядок импортов и стиль именования.
- Не менять поведение других разделов «попутно»: сначала описать, что именно меняется.
- Типы не ослаблять (`any` не добавлять); если тип нужно расширить — расширять в `src/types/index.ts`.

## Деплой (только по явной просьбе)

Прод — статическая сборка на хостинге Beget, домен `agenthub.yantpp.ru`, каталог `public_html`.

Порядок: `npm run build` → упаковать содержимое `dist` в zip (по образцу `public/dist-beget.zip`) → загрузить и распаковать архив в `public_html` через файловый менеджер Beget. Файл `.htaccess` уже включён в архив — SPA-роутинг настраивать не нужно.

## Отчёт о работе

В финальном сообщении кратко перечислить: какие файлы изменены, что именно сделано, как это проверено (какие команды запускались и с каким результатом).
